# v1.0 — Known Limitations

> Stand: v1.0.0-rc.1. Feature-Complete RC. Kein stabiler v1.0.0-Tag.

## Job-Queue / Async
- **In-Process-Queue, keine Hochverfügbarkeit.** Laufende Jobs können bei
  API-Prozess-Absturz verloren gehen (Status in SQLite, nicht fortgesetzt).
- Kein Cloud-Worker, keine verteilte Queue. Bewusst nicht als "gelöst"
  dargestellt — siehe `docs/job-queue.md`.

## Reproduzierbarkeit / Exporte
- **PDF / Excel:** durch interne IDs/Zeitstempel oft NICHT byte-identisch als
  Datei. Der fachliche `result_hash` ist der Identitätsnachweis.
- CSV / JSON / NumPy: bei gleichen Inputs byte-identisch möglich.
- Fehlende Daten werden nicht stillschweigend ersetzt (Drift → Abbruch/Rerun).

## Portfolio & Rebalancing
- ✅ Mindestordergrößen & Stückelung (P1.2) — gelöst.
- Keine Portfolio-Ziele / Risiko-Budgets (P2).
- Steuer-/Kostenschätzungen sind Pauschalen (25 % TLH), keine Steuerberatung.

## Plattform
- **Windows-Installer:** Build-Umgebung hatte kein Inno Setup (ISCC fehlt).
  Inzwischen extern nachgeholt: ISCC 6.7.3 installiert, Installer
  `LocalMarketLab-Setup-v1.0.0.1.exe` erfolgreich gebaut und geprüft
  (silent Install/Uninstall sauber, Version 1.0.0.1 in Registry,
  SHA256: cbe54904…bfdada). Hinweis: Installer-Build ist NICHT
  byte-reproduzierbar (Inno Setup bettet Zeitstempel ein) — Prüfsumme pro
  Build dokumentieren. Portable EXE bleibt zusätzlich verfügbar.
  Saubere Windows-VM-Test noch offen (externer RC-Zyklus).
- Desktop-App benötigt PyQt6 (optional-extras `desktop`).

## Analytics-Claims (vorsichtig formuliert)
- "Look-ahead-Bias geprüft" — nicht absolut "unmöglich".
- "SHAP-like approximation" — keine vollständige SHAP-Implementierung.
- "institutionally inspired analytics" — keine externe Zertifizierung.
- "100% local" — mit Hinweis auf optionale externe Marktdatenprovider.
- Keine Garantie zukünftiger Renditen; keine Kauf-/Verkaufsempfehlung.
