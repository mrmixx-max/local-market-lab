# v1.0 RC External Test Plan

**Pre-Release:** v1.0.0-rc.1 — nur für externe Stabilisierung. Kein stabiler v1.0.0-Tag.

Jeder Test: Umgebung / Schritte / Erwartet / Tatsächlich / PASS-FAIL / Log/Screenshot / Datenschutz.
Keine API-Keys oder privaten Portfoliodaten in Feedback einfügen.

## 1. Installation
- Umgebung: frische Python-3.11-Umgebung (venv)
- Schritte: `pip install local-market-lab==1.0.0rc1` (wheel) oder `pip install -e .`
- Erwartet: Import + `lml demo` funktionieren
- Datenschutz: keine Netzwerkaufrufe ohne explizite Datenquelle

## 2. Start (Desktop/Web/CLI)
- Schritte: `python -m apps.api` + Browser `http://127.0.0.1:8322/`
- Erwartet: Web-UI lädt, Jobs-Tab (F9) sichtbar

## 3. Demo-Daten
- `lml demo` → synthetische Preise + Transaktionen
- Erwartet: Portfolio-Valuation gedruckt

## 4. CSV-Import
- `lml import prices FILE SYMBOL` mit lokalem CSV
- Erwartet: Preise importiert, Data-Hash generiert

## 5. Marktdaten (optional)
- `lml import market SYMBOL --adapter yahoo` (benötigt yfinance)
- Erwartet: Bars importiert; ohne Key kein Fehler im Offline-Modus

## 6. Offline-Modus
- Kein Netzwerk → nur lokale/synthetische Quellen
- Erwartet: kein stiller Fallback auf externe Daten

## 7. Backtest (synchron)
- `lml backtest demo` → Metriken (CAGR, Sharpe, MaxDD)
- Erwartet: numerisch plausibel, Manifest gespeichert

## 8. Job-Queue
- `lml jobs list`, `lml jobs submit` via API, `lml jobs wait <id>`
- Erwartet: Status queued→running→succeeded; Exit 0 bei succeeded

## 9. Fortschritt
- Während Job: `lml jobs status <id>` zeigt 0<progress<1
- Erwartet: steigt monoton, API bleibt responsiv

## 10. Cancel
- `lml jobs cancel <id>` während running
- Erwartet: Status→cancelled, idempotent

## 11. Validation
- `POST /api/v1/validation/run` → Walk-Forward-Splits deterministisch

## 12. Stress-Test
- `lml scenario stress` → Szenario-Metriken

## 13. Rebalancing + Mindestordergrößen
- Rebalancing-Vorschlag mit `LML_REBALANCE_DEFAULT_MIN_ORDER_VALUE=50`
- Erwartet: Orders < 50 € als `below_minimum` markiert

## 14. Manifest-Erzeugung
- Jeder Lauf schreibt `data/manifests/<id>.json` mit manifest_digest

## 15. Rerun
- `lml rerun <id>` → Vergleichsreport
- Erwartet: bei identischen Voraussetzungen `Result: BYTE-IDENTICAL`

## 16. Exporte
- PDF / Excel / CSV aus einem Backtest
- Erwartet: Disclaimer + Run-ID + Seed + Data-Hash im Manifest verknüpft

## 17. Windows-App
- `LocalMarketLab.exe` starten → Jobs-Tab funktional
- Datenschutz: keine Secrets in Logs

## 18. CLI / Web-UI
- Vollständige Abdeckung der obigen Punkte über beide Oberflächen

## Feedback-Kanal
- GitHub Issues (ohne Secrets/Portfolio-Daten)
- `lml jobs`, `lml manifests` Ausgaben sind sicher (keine Secrets)
