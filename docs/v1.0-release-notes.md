# Local Market Lab v1.0.0-rc.2 — Release Notes

> **PRE-RELEASE / RELEASE CANDIDATE** — nicht für Produktionseinsatz.
> Dient ausschließlich der finalen Stabilisierung und externen Tests.

## Ziel
Feature-Complete v1.0 als Release Candidate. P1.1–P1.4 vollständig integriert.
Kein `v1.0.0`-Stable-Tag in diesem Release.

## Highlights
- **P1.1 Job-Queue (Backend):** In-Process-Worker, SQLite/WAL-Persistenz,
  Submit→Progress→Result, Cancel, Artifact-Referenzen. API blockiert nicht.
- **P1.2 Mindestordergrößen:** `suggest_rebalance_orders()` mit konfigurierbaren
  Mindestbeträgen, ganzzahlig/Fractional-Modi, Kosten-Nutzen-Check,
  `below_minimum`-Markierung (kein stilles Runden).
- **P1.3 Client-Binding:** `lml jobs` (list/status/cancel/wait/artifact) +
  Desktop (F9) + Web-UI (F9) über ein gemeinsames Statusmodell.
- **P1.4 Manifeste & Reproduzierbarkeit:** immutable Run-Manifeste, kanonische
  Hashes (manifest_digest, parameters/data/model/environment/result_hash),
  `lml rerun <id>` (synchron/async), Drift-Erkennung, byte-identischer
  fachlicher Result-Hash bei identischen Voraussetzungen.

## API-Endpunkte (additiv)
- `POST /api/v1/jobs`, `GET /api/v1/jobs`, `GET /api/v1/jobs/{id}`,
  `DELETE /api/v1/jobs/{id}`
- `GET /api/v1/manifests`, `GET /api/v1/manifests/{id}`,
  `GET /api/v1/manifests/{id}/compare`, `POST /api/v1/manifests/{id}/rerun`
- Alle bestehenden Endpunkte unverändert (kein Breaking Change).

## Exportformate
- JSON, CSV, Excel, PDF — verknüpft mit Run-ID, Seed, Data-Hash, Disclaimer.

## Tests & Coverage
- **462 Tests grün**, 6 skipped (Live-CLI/Async ohne Server)
- Coverage 78% gesamt, kritische Module 82–100%
- Secret-Scan clean, pip-audit/SBOM erstellt, Clean-Venv validiert
- Reproduzierbarkeit: 3/3 identische Läufe (param/data/result-Hash)

## Bekannte Einschränkungen
- **In-Process-Queue:** keine Hochverfügbarkeit; laufende Jobs können bei
  API-Absturz verloren gehen (Status in SQLite, nicht fortgesetzt).
- **Windows-Installer:** in dieser Build-Umgebung nicht reproduzierbar
  (Inno Setup/ISCC fehlt) — portable EXE ist das primäre Windows-Artefakt.
- **PDF/Excel:** können durch technische Metadaten nicht byte-identisch sein;
  der fachliche `result_hash` ist die Identitätsquelle.
- **Keine Portfolio-Ziele/Risiko-Budgets** (P2, nicht in v1.0-Scope).
- **Keine** Broker-, Order- oder Finanzberatungsfunktionen.

## Installation
```bash
pip install local-market-lab==1.0.0rc2   # wheel (PyPI, so available)
# oder aus Source:
git clone <repo> && cd local-market-lab && pip install -e .
python -m apps.api        # API + Web-UI auf http://127.0.0.1:8322/
lml demo                  # Demo-Daten + Pipeline-Smoke-Test
```
