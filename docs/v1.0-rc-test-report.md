Im RC **nicht gebaut**: Inno Setup/ISCC fehlt in der Build-Umgebung.
Das ist eine Build-Umgebungs-Limitation, **kein Produkt-Bug**, aber auch nicht
als erledigt markiert. Siehe `docs/v1.0-known-limitations.md`.
Portable EXE bleibt primäres Windows-Artefakt bis ein reproduzierbarer
Installer-Build auf einer sauberen Umgebung vorliegt.
